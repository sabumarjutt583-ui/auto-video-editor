Install notes

  • Windows: if “Windows protected your PC” appears, click More info, then Run anyway.
  • Mac: if the app cannot be opened, right-click the app, choose Open, then Open again.
  • Linux: make the AppImage executable (right-click > Properties > Allow executing) or use the .deb.
