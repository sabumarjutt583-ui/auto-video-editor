# Auto Editor - downloads

**Auto Editor** makes prompts for your narration videos and then edits the video for you: timeline, captions in many languages, music, sound effects and a finished MP4. It is a free desktop app for Windows, macOS and Linux. Everything is included: all caption fonts (Korean, Japanese, Chinese, Nepali/Hindi, Urdu, Russian and more), all styles and a sound-effects library. After the install it works offline (only Groq and Gemini need the internet, with your own keys).

## Install notes

The app is free but not signed with a paid certificate, so your system shows a warning the first time. This is normal.

- **Windows:** run the `.exe`. If "Windows protected your PC" appears, click **More info**, then **Run anyway**.
- **Mac:** open the `.dmg` and drag Auto Editor to Applications. If it cannot be opened, **right-click** the app, choose **Open**, then **Open** again.
- **Linux:** for the AppImage, right-click the file > Properties > **Allow executing as a program**, then open it. Or install the `.deb`.

## Updates

The app checks for new versions by itself a few seconds after it starts (at most once a day). Press **Update now** in the bar at the top - your projects are never touched. You can also use Settings > Updates > Check for updates.
