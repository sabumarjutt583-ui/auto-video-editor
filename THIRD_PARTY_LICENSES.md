# Third-party material

Auto Video Editor ships the following third-party material. Only the data files listed here are bundled; none of these packages is a dependency of the app (the files were converted once by `scripts/build-graphic-assets.mjs` and `scripts/build-flags.mjs` and committed under `src/lib/graphics/assets/`). Nothing is loaded from the internet: maps, flags and icons all work offline, and no Google Maps or online map tiles are used.

| Material | Used for | Licence | Source |
|---|---|---|---|
| Lucide icons 1.61.0 | default icon set of motion graphics (1,903 icons) | ISC (some icons MIT, from Feather) | https://lucide.dev |
| Tabler Icons 3.49.0 | second icon set (5,184 outline + 1,054 solid icons) | MIT | https://tabler.io/icons |
| flag-icons 7.6.0 | country flags (250 flags, drawn once to WebP pictures) | MIT | https://github.com/lipis/flag-icons |
| world-atlas 2.0.2 | country outlines (TopoJSON, 110m and 50m), made from Natural Earth | ISC (package); data is public domain | https://github.com/topojson/world-atlas |
| Natural Earth populated places (1:50m) | cities table (1,248 places: name, country, position, other-language names) | Public domain | https://www.naturalearthdata.com |
| i18n-iso-countries 7.14.0 | ISO 3166-1 codes and country names in 9 languages | MIT | https://github.com/michaelwittig/node-i18n-iso-countries |
| Noto Sans fonts (Latin, KR, JP, SC, Devanagari, Arabic) | captions and motion graphics text | SIL Open Font License 1.1 | https://fonts.google.com/noto |

Natural Earth says: "All versions of Natural Earth raster + vector map data found on this website are in the public domain. You may use the maps in any manner, including modifying the content and design, electronically, in printed form, or as a part of a mobile application. Attribution is not required."
